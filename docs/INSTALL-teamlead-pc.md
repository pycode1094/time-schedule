# 알림톡 발송 도우미 설치 안내 (팀장님 PC)

시간표를 올리는 PC에 **"알림톡 발송 도우미"** 를 한 번 설치하는 방법입니다. 설치하고 나면 PC를 켤 때마다 도우미가 화면 없이 자동으로 실행됩니다. 시간표 사이트에서 **[업로드 + 알림 발송]** 을 누르면 일정이 바뀐 강사님께 카카오 알림톡이 갑니다.

- 걸리는 시간: 약 20분
- 필요한 것: 담당자가 준비한 USB, 담당자가 **직접** 알려주는 값 4가지
  - 비즈고 API 키
  - 발신 프로필 키
  - 이 사무실의 공인 IP
  - (필요하면) 테스트용 휴대전화 번호

> **⚠ API 키는 카카오톡·메일·메신저로 주고받지 마세요.** 담당자가 이 PC 앞에서 직접 입력하거나, 종이·USB로 전달합니다. 채팅창(AI 포함)에도 붙여넣지 마세요.

> 이 문서의 IP `203.0.113.10`은 **예시**입니다. 실제 공인 IP는 담당자가 따로 알려드립니다.

---

## 1. Node.js 설치

1. https://nodejs.org 에 들어가 **LTS** 버전(20 이상)을 내려받아 설치합니다. 설치 화면은 모두 기본값으로 [Next]를 누르면 됩니다.
2. 설치가 끝나면 **시작 메뉴 → "PowerShell"** 을 열고 아래를 입력한 뒤 Enter를 누릅니다.
   ```
   node -v
   ```
   `v20.x.x` 이상(예: `v22.11.0`)이 나오면 됩니다. "인식할 수 없는 명령"이 나오면 PC를 다시 시작한 뒤 한 번 더 해 보세요.

## 2. 폴더 복사 (USB)

1. USB에 있는 **`time-schedule`** 폴더를 **`C:\time-schedule`** 로 복사합니다.
2. 다음 두 파일이 있는지 확인합니다.
   - `C:\time-schedule\notify-helper\server.js`
   - `C:\time-schedule\scripts\install-notify-helper.ps1`

## 3. 설정 파일(`.env`) 만들기

1. `C:\time-schedule\notify-helper` 폴더를 엽니다.
2. `.env.example` 파일을 복사해 같은 폴더에 붙여넣고, 이름을 **`.env`** 로 바꿉니다.
   - 탐색기에서 [보기] → [파일 확장명]에 체크하면 이름을 정확히 볼 수 있습니다. **`.env.txt`가 되면 안 됩니다.**
3. `.env`를 메모장으로 열어 아래 줄들을 찾아 `=` 뒤를 채웁니다. 나머지 줄은 그대로 둡니다.

   | 줄 | 넣을 값 |
   |---|---|
   | `NOTIFY_DRY_RUN=` | `false` |
   | `BIZGO_API_KEY=` | 담당자가 직접 입력 (`mars_ak_`로 시작) |
   | `BIZGO_BASE_URL=` | `https://mars.ibapi.kr/api/comm` |
   | `BIZGO_SENDER_KEY=` | 담당자가 직접 입력 |
   | `BIZGO_TEMPLATE_CODE=` | `01000_2_20` |
   | `EXPECTED_PUBLIC_IPS=` | 담당자가 알려준 공인 IP (예: `203.0.113.10`) |
   | `NOTIFY_TEST_PHONE=` | **비워 둠** (값이 있으면 모든 알림이 그 번호로만 갑니다) |
   | `ALLOWED_ORIGINS=` | `https://pycode1094.github.io` (뒤에 `/time-schedule/` 붙이지 않음) |

4. 저장할 때 메모장의 [다른 이름으로 저장]에서 **인코딩은 UTF-8**, 파일 형식은 **모든 파일**로 하고 이름을 `.env`로 저장합니다.

## 4. 설치 스크립트 실행

1. 탐색기에서 `C:\time-schedule` 폴더를 연 뒤, 주소창에 `powershell`이라고 입력하고 Enter를 누릅니다. 이 폴더에서 PowerShell 창이 열립니다.
2. 아래 한 줄을 붙여넣고 Enter를 누릅니다.
   ```
   powershell -ExecutionPolicy Bypass -File scripts\install-notify-helper.ps1
   ```
3. 스크립트가 하는 일:
   - Node.js 버전 확인
   - `.env`를 **이 Windows 사용자만** 열 수 있게 권한 설정
   - "로그온 시 자동 실행" 등록 (작업 이름 `TimeSchedule-NotifyHelper`)
   - 바로 실행
4. 마지막에 초록색 **"설치 완료."** 와 함께 아래 같은 줄이 나오면 성공입니다.
   ```
   모드 production · 발송 켜짐 · API 키 ok · 공인 IP 203.0.113.10 (ok)
   ```
   노란 경고가 나오면 아래 "문제 해결"을 보세요.

## 5. 자동 실행 확인

1. 브라우저(크롬·엣지) 주소창에 **`http://127.0.0.1:5599/health`** 를 입력합니다.
2. 글자가 잔뜩 나오면 도우미가 실행 중인 것입니다. 그중 다음을 확인합니다.
   - `"mode":"production"`
   - `"enabled":true`
   - `"ok":true`
3. PC를 **다시 시작**한 뒤 로그인하고, 1~2분 뒤 같은 주소를 다시 열어 똑같이 나오는지 확인합니다. 로그인 직후 검은 창이 잠깐 깜빡일 수 있는데 정상입니다.

## 6. 공인 IP 확인

1. 위 `/health` 화면에서 **`"publicIp"`** 값을 봅니다(예: `"publicIp":"203.0.113.10"`).
2. 이 값이 **담당자가 알려준 IP와 같은지** 확인합니다.
   - 같으면 `"ipStatus":"ok"`로 나옵니다.
   - **다르면** (`"ipStatus":"mismatch"`) 알림이 나가지 않습니다. 화면에 보이는 `publicIp` 값을 담당자에게 알려 **비즈고 허용 IP 추가**를 요청하세요. 추가가 끝나면 `.env`의 `EXPECTED_PUBLIC_IPS=`에 그 IP를 쉼표로 덧붙입니다(예: `203.0.113.10,198.51.100.20`).
   - 사무실 인터넷 회선이 바뀌면 공인 IP도 바뀔 수 있습니다.

## 7. 시간표 사이트에서 확인

1. **https://pycode1094.github.io/time-schedule/** 에 들어가 오른쪽 위 **[관리자]** 로 로그인합니다.
2. 종합시간표 엑셀을 선택하면 "업로드 전 변경 내용 확인" 창이 뜹니다.
   - 처음에 브라우저가 **"로컬 네트워크의 기기에 액세스"** 같은 권한을 물으면 **[허용]** 을 누릅니다.
3. 창 아래쪽에 초록색으로 다음이 보이면 준비가 끝난 것입니다.
   > **발송 도우미 연결됨 · production · IP 정상 (203.0.113.10)**
   > 실제 강사 번호로 발송됩니다
4. 확인만 할 때는 [취소]를 누르면 아무것도 올라가거나 발송되지 않습니다.

**평소 사용**: 시간표를 올릴 때 [업로드 + 알림 발송]을 누르면, 체크된 강사님께 알림톡이 갑니다. 결과(접수/실패와 사유)는 관리자 창에 나옵니다. 알림 없이 올리려면 [업로드만]을 누르세요.

## 문제 해결

| 화면에 보이는 것 | 할 일 |
|---|---|
| **"발송 도우미가 꺼져 있습니다"** / `http://127.0.0.1:5599/health`가 안 열림 | ① 시작 메뉴 → "작업 스케줄러" → 왼쪽 "작업 스케줄러 라이브러리"에서 `TimeSchedule-NotifyHelper`를 찾아 오른쪽 [실행]. ② 그래도 안 되면 `C:\time-schedule\notify-helper\logs\start-error.txt`의 내용을 담당자에게 전달. ③ 4번(설치 스크립트)을 한 번 더 실행 |
| **"IP 불일치"** / "현재 공인 IP x.x.x.x 가 비즈고 허용 IP에 없습니다" | 화면의 IP를 담당자에게 알려 비즈고 허용 IP 추가를 요청하고, `.env`의 `EXPECTED_PUBLIC_IPS`에도 추가 (6번) |
| 발송 결과에 **템플릿 관련 오류**(템플릿 불일치, 템플릿 코드 오류 등) | 담당자에게 결과 화면을 그대로 전달. 문구는 `notify-helper\templates.json`에 있으며 **비즈고에 등록된 문구와 글자 하나까지 같아야** 합니다. 임의로 고치지 마세요 |
| "BIZGO_API_KEY …" / "발신 프로필 키…" 가 비어 있다는 안내 | `.env`의 해당 줄 값 확인. 키는 담당자가 직접 입력 |
| "시간당 발송 요청 한도" | 안내된 시각 이후에 다시 올리기 |
| `.env`를 고친 뒤 권한 안내가 나오거나 설정이 반영되지 않음 | 4번 설치 스크립트를 다시 실행 (권한을 다시 걸고 도우미를 다시 시작) |

### 긴급 정지 (알림이 잘못 나가는 것 같을 때)

1. 메모장으로 `C:\time-schedule\notify-helper\.env`를 엽니다.
2. `NOTIFY_ENABLED=` 줄을 **`NOTIFY_ENABLED=false`** 로 바꾸고 저장합니다.
3. **재시작 없이 바로** 모든 발송이 막힙니다. 시간표 사이트에는 "발송이 꺼져 있습니다"가 표시되고, [업로드만]은 그대로 됩니다.
4. 담당자에게 알립니다. 다시 켤 때는 `false`를 지워 `NOTIFY_ENABLED=`로 둡니다.

### 제거

`C:\time-schedule`에서 PowerShell을 열고:
```
powershell -ExecutionPolicy Bypass -File scripts\uninstall-notify-helper.ps1
```
자동 실행과 실행 중인 도우미를 지웁니다. `.env`(API 키 들어 있음)는 남으니, PC를 더 쓰지 않으면 담당자와 함께 지우세요.
